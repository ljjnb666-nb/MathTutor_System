## 2. 关键代码实测纠偏总结 (Audited Grounding Truth)

1. **出题与内容**：
   - 原臆测 `textbookApi` 不存在，实际为 `getBankList`, `generateQuestions`, `generateExam` (`services/api`) 与 `constants/textbooks`。
   - 原臆测 `teacherAgentApi.runTask` 不存在，实际为 `createTeacherAgentRun`, `getTeacherAgentRunArtifacts`, `confirmPracticeAction` 等 10 个显式动作 (`services/teacherAgentApi`)。
   - 原臆测 `knowledgeBaseApi.getDocuments` 不存在，实际为 `listRagDocuments`, `uploadRagDocument`, `getRagDocumentChunks`, `deleteRagDocument` (`services/api`)。
   - 原臆测 `homeworkApi.getProgress` 不存在，实际通过试卷管理模型 `getExams`, `saveExam`, `updateExam` 进行学生任务投影。
2. **系统与管理**：
   - 原臆测 `subscriptionApi.getPlans` 不存在，实际为 `getPlans`, `getPaymentConfig`, `createOrder` (`services/api`)。
   - 原臆测 `adminApi.getUsers` 不存在，实际为 `listUsers`, `createUser`, `deleteUser`, `setUserSubscription` (`services/api`)。
   - 原臆测 `settingsApi.getAiConfig` 不存在，实际通过 `services/llmApi` (`testLlmConnection`, `getLlmRuntimeStatus`) 与 `constants/ai-providers` 本地存储同步。
3. **架构与业务事实**：
   - 全页面 API 依赖均已确认映射到实际 `services/*` 导出的权威函数，所有非 API 本地状态页面已确认为 `LOCAL_ONLY` 或 `CONTEXT_ONLY`。
